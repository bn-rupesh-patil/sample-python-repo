## Educational Resources

### Bad Coding Practices Example

This repository contains `bad_example.py` - a Python script that intentionally demonstrates poor coding practices for educational purposes. This script showcases various anti-patterns and violations of Python best practices including:

- **Global variables abuse**: Excessive use of global variables throughout the script
- **Inconsistent naming conventions**: Mixing camelCase, snake_case, and PascalCase
- **Poor structure**: Lack of proper function/class organization
- **No documentation**: Missing docstrings and meaningful comments
- **Poor error handling**: Bare except clauses and silent failures
- **Magic numbers**: Hardcoded values without explanation
- **Long lines**: Code that violates PEP 8 line length guidelines
- **No type hints**: Missing type annotations
- **Multiple responsibilities**: Single script doing too many unrelated things
- **Security issues**: Hardcoded API keys and poor input validation

**⚠️ WARNING**: This code is intentionally written poorly for educational purposes. Do NOT use this as a reference for writing production code!
